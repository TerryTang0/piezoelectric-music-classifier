# Piezoelectric Music Classifier

## Background

This project comes from my undergraduate research in the FLEX Lab at Purdue University, where I fabricated piezoelectric sensors and used them to measure and analyze my own pulse signals.

The main question I wanted to explore was:

Can changes in my pulse while listening to music be used to identify what kind of music I am listening to?

To test this, I recorded my pulse while listening to different songs and used the collected pulse waveforms to build a music classification model.

The model does not analyze the music audio directly. Instead, it reads the pulse signal measured by the piezoelectric sensor and looks for patterns in pulse rate, waveform shape, amplitude, and frequency-related features that may be associated with different music genres.

## Abstract

I fabricated 35 piezoelectric sensors during this project. Out of those, 3 sensors produced stable and usable pulse measurements for further experiments.

Using these sensors, I recorded my pulse while listening to different songs and collected a larger set of pulse measurements. After reviewing the recordings, I selected 26 samples with clear and usable pulse patterns for analysis. These samples cover six music genres: Electronic, Modern Pop, Country, Piano, R&B, and Rap.

The pulse current generated by the piezoelectric sensor was measured using a low-noise current preamplifier and recorded through LabVIEW.

The recorded pulse signals were then processed in Python using filtering, window segmentation, and feature extraction. Each signal window was represented by 19 numerical features describing pulse strength, timing, waveform shape, energy, and frequency distribution.

Five machine-learning models were evaluated to determine whether the pulse signal could be used to predict the genre of music I was listening to. To reduce data leakage, windows from the same music recording were kept together during cross-validation.

Among the five models, Random Forest achieved the highest mean Macro F1 score of 0.4726 ± 0.0675. Across all out-of-fold predictions, it correctly classified 769 of 1,459 pulse-signal windows, giving an overall accuracy of 52.7%.

## Sensor Fabrication

The sensors were fabricated using a flexible **Ecoflex substrate**.

The main fabrication steps were:

1. Prepare the Ecoflex base.
2. Add the liquid-metal electrode/bar to the Ecoflex.
3. Soak the device in a solution containing `H2SO4`, `Zn(NO3)2·6H2O`, and `H2O`.
4. Leave the device in the solution for approximately **6 hours**.

A total of **35 sensors** were fabricated, and **3 produced stable enough responses** for the music experiments.

## Code Structure

The analysis is divided into five Python files inside the `Code/` folder:

- `labels.py` — assigns the genre and song ID from each filename
- `loader.py` — reads the LabVIEW data and preprocesses the current signal
- `features.py` — extracts numerical features from each signal window
- `dataset.py` — builds the machine-learning dataset
- `main.py` — trains and evaluates the classification models

---

## Signal Processing Pipeline

The raw LabVIEW current signal first goes through signal preprocessing:

1. The DC offset is removed, followed by a **0.5–450 Hz Butterworth band-pass filter**.
2. Each recording is divided into **5-second windows with 50% overlap**.
3. Nineteen features are extracted from every window and used as input to the machine-learning models.

The complete dataset contains:

- **1,459 signal windows**
- **26 original music recordings**
- **19 features per window**

The overall pipeline is:

**Raw signal data → Signal preprocessing → 5-second windows → Feature extraction → Dataset construction → Grouped cross-validation → Model comparison → Music genre prediction**

---

## Feature Engineering

For each 5-second signal window, I extract **19 features** that describe the amplitude, shape, timing, energy, and frequency distribution of the electrical signal.

### Amplitude and Energy

- RMS
- Maximum amplitude
- Crest factor
- Signal-to-noise ratio
- Log total power
- Energy entropy

These features describe the overall strength and energy of the current signal.

### Signal Shape

- Skewness
- Kurtosis
- Zero-crossing rate

These features describe the shape and statistical distribution of the waveform.

### Pulse Timing

- BPM
- Tempo variation coefficient

These features are based on the spacing between detected electrical peaks.

The BPM value is treated as an estimate of the **electrical pulse rate**, rather than the exact musical BPM of the original song.

### Frequency-Domain Features

- Sub-bass band power: 5–35 Hz
- Bass band power: 35–100 Hz
- Mid-frequency band power: 100–250 Hz
- High-frequency band power: 250–450 Hz
- Sub-bass-to-mid ratio
- Bass-to-high ratio
- Spectral centroid
- Spectral flux

These features describe how the signal energy is distributed across different frequency ranges.

## Machine-Learning Models

I select 5 machine-learning models to evaluate and compare different approaches to the classification problem:

| Model | Why It Was Included |
| :--- | :--- |
| **Logistic Regression** | Provides a simple linear baseline and helps show whether the extracted features can be separated using a linear decision boundary. |
| **k-Nearest Neighbors** | Uses similarity between samples and provides a simple non-parametric comparison without assuming a specific decision boundary. |
| **Support Vector Machine** | The RBF kernel can capture non-linear relationships between the signal features and works well with smaller datasets. |
| **Gradient Boosting** | Builds decision trees sequentially and can learn more complex relationships between multiple features. |
| **Random Forest** | Combines many decision trees, handles non-linear feature interactions well, is relatively robust to noisy data, and provides feature-importance values. |

Using several different model types made it possible to compare linear, distance-based, kernel-based, and tree-based approaches using the same feature dataset.

Among the five models, **Random Forest produced the best overall cross-validation performance**.

---

## Model Evaluation

Each original song produces many overlapping 5-second windows.

If these windows were randomly divided into training and testing sets, windows from the same song could appear in both sets. The model could then learn characteristics specific to that recording instead of learning patterns that generalize to other songs.

To avoid this, I use **Stratified Group K-Fold cross-validation**.

All windows from the same song stay together in the same fold, so a song used for testing does not also appear in the training data for that fold.

The main metric used to compare the models is **Macro F1**, since the number of recordings is not balanced across all six genres.

## Results

### Model Tournament Leaderboard

| Model | Mean Macro F1 | Std. Dev. |
| :--- | :---: | :---: |
| **Random Forest** | **0.4726** | **± 0.0675** |
| Gradient Boosting | 0.4496 | ± 0.1026 |
| k-Nearest Neighbors | 0.3603 | ± 0.1099 |
| Support Vector Machine | 0.3145 | ± 0.1135 |
| Logistic Regression | 0.2590 | ± 0.0704 |

Random Forest achieved the highest mean Macro F1 score across unseen tracks.

Across all out-of-fold window predictions, the Random Forest model achieved **52.7% accuracy** (769 of 1,459 windows correctly classified). For comparison, random guessing across six classes corresponds to an accuracy of approximately 16.7%.

Modern Pop, R&B, and Rap showed the strongest classification performance in the dataset. Country was the most challenging genre for the model to separate, often showing dynamic overlap with Electronic and Modern Pop tracks.

### Top Feature Importances (Gini Gain)

The 10 most influential features identified by Random Forest were:

1. `band_bass` (0.1485)
2. `log_bass_to_high` (0.1441)
3. `rms` (0.0815)
4. `energy_entropy` (0.0693)
5. `spectral_centroid` (0.0656)
6. `snr_db` (0.0641)
7. `max_amplitude` (0.0627)
8. `band_sub_bass` (0.0589)
9. `log_sub_to_mid` (0.0580)
10. `bpm` (0.0454)

Low-frequency physical vibrations (`band_bass` and `log_bass_to_high`) contributed the most to separating genres, as bass drum hits and sustained basslines create the largest mechanical deflections on the flexible sensor membrane.

---

## Conclusion

The results show that the electrical signals generated by the piezoelectric sensors contain patterns that can be used to distinguish between different music genres to some extent.

Among the five candidate models, **Random Forest performed best**, reaching a mean Macro F1 score of **0.4726 ± 0.0675** and an overall out-of-fold accuracy of **52.7%**.

The model performed well particularly on **Modern Pop, R&B, and Rap**, while **Country** was the most difficult genre to classify. The feature-importance results also showed that frequency distribution, signal amplitude, energy, and pulse timing all contributed to the predictions.

Overall, the project demonstrates that the measured piezoelectric response contains useful information for music classification, while also showing that performance varies significantly across genres.
